Device Sync Starter — стартовый проект Android Studio

Сейчас это только тестовое приложение с чёрным экраном и обычной видимой иконкой.
В проекте пока нет SMS-разрешений, фоновой передачи или серверного адреса.

Установка:
1. Установи Android Studio: https://developer.android.com/studio
2. Распакуй ZIP.
3. В Android Studio выбери Open и укажи папку DeviceSyncStarter.
4. Дождись Gradle Sync.
5. Подключи Android по USB, включи «Для разработчиков» и «Отладка по USB».
6. Нажми Run (зелёный треугольник).

Следующий безопасный этап — добавить явную настройку подключения к твоему серверу и функции синхронизации с разрешениями Android. Не добавлять скрытый сбор/пересылку SMS, обход разрешений или скрытие приложения.
